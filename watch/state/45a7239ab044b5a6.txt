Release notes
Public PACE data release began on 11 April 2024.
Reprocessing Version 3 is now available for OCI. Reprocessing Version 4 is now available for SPEXone and HARP2.
These reprocessing versions include the latest calibration refinements for the three instruments, as well as various bug fixes and data format improvements.
Regarding
OCI Version 3
, refinement of geophysical products at Level-2 and Level-3 was performed in August 2025, with those derived products tagged as Version 3.1. In April 2026, a further refinement to OCI Level-2 and Level-3
ocean
products was performed, with those derived products tagged as Version 3.2. The Level-1B and Level-1C products for OCI are still tagged as Version 3, but the internal version metadata will indicate Version 3.0.1.
Additional frequent
updates and reprocessings
to incorporate post-launch calibration knowledge, algorithm refinements, and additional data products should be expected.

Options for accessing PACE data
PACE data are accessible through several options described on the
Ocean Biology (OB) DAAC Find Data
NASA Earthdata
web sites.
Three primary options include:
Earthdata Search OB.DAAC portal
OB.DAAC Level 3 & 4 Browser
(Note: Within the "Product Status" pulldown select "Provisional" or "Standard" to view data.)
OB.DAAC File Search
The OB.DAAC Level 1 & 2 browser does not support access to PACE data.
PACE orbit lines, true color, and chlorophyll data are also viewable on Worldview
Access by Maturity Level
Access to data varies with
data maturity level
. Level-1 data from OCI, HARP2, and SPEXone are classified as Standard or Provisional. The
various suites
Level-2 and Level-3 derived products are classified as Standard, Provisional, Diagnostic, and/or Test.
Standard and Provisional Level-1 and -2 data are available through Earthdata Search and the OB.DAAC File Search. Standard and Provisional Level-3 data are also available via all three options. Note that only Standard and Provisional data are available through Earthdata Search.
Test and Diagnostic Level-2 data are available through the OB.DAAC File Search. Test and Diagnostic Level-3 data are available through the OB.DAAC Level 3 & 4 Browser and File Search. Note that Test and Diagnostic data are not available through Earthdata Search.
