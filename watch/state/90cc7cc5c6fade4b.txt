CORe is an atmospheric reanalysis from the Climate Prediction Center NCEP/NWS/NOAA
with collaboration with the Environmental Modeling Center NCEP/NWS/NOAA and Physical Sciences
Laboratory NOAA. CORe analyses can be obtained from the NCEP Nomads site, and the NODD
(NOAA Open Data Dissemination) service which distributes NOAA data by the cloud.

The NCEP Nomads site is run by NCEP Central Operations (NCO) using data from
the operational run of CORe. You can submit help tickets, subscribe to mailing
lists and read their documentation at
NCO help and information
NCO has 24 hour support.
More information will be provided after CORe data is sent the Nomads site.
The CORe files on NODD can be downloaded using
https://ftp.cpc.ncep.noaa.gov/CORe/get_core/get_core.py
Documentation is in
https://ftp.cpc.ncep.noaa.gov/CORe/get_core/get_core.txt
The Climate Prediction Center (CPC) is responsible for updating the NODD archive, and
maintaining get_core.py. CPC support is limited to office hours.
In the event that CORe needs to be rerun, it is expected that the new analyses
would be sent to the NODD archive and not NCEP's nomads site.
