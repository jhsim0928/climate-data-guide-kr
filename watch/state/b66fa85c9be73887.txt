Version Summary
Version 4 is derived from ATL10 v7. Changes include: temporal coverage extended through April 2026; provided e5 reanalysis and m2 reanalysis forced SnowModel-LG snow loading and resultant sea ice thickness; added grid cell area parameter; added time parameter.

Overview
This data set provides monthly, gridded, winter Arctic sea ice thickness, freeboard, ice density, snow depth, and snow density estimates derived from ICESat-2 L4 Along-Track Sea Ice Thickness (IS2SITDAT4).
