October 23, 2026
Data set updates: SMAP Level-4
The SMAP Level-4 data sets, available at the NASA National Snow and Ice Data Center Distributed Active Archive Center (NSIDC DAAC), have been updated to a new minor version for data beginning 1 August 2023. This update makes improvements to L1C_TB quality control, IMERG late inputs, and a geolocation issue fix (14 May 2026 to 28 July 2026). These changes are reflected in updated Science Version IDs (Vv8012, Vv8013).

New data set release: Near Real-Time VIIRS/JPSS-1 L3 Global Daily 500m SIN Grid Snow Cover, Grain Size, and Dust Radiative Forcing, Version 1
The Near Real-Time VIIRS/JPSS-1 L3 Global Daily 500m SIN Grid Snow Cover, Grain Size, and Dust Radiative Forcing, Version 1 data set is now available at the NASA National Snow and Ice Data Center Distributed Active Archive Center (NSIDC DAAC). This data set includes parameters from two different algorithms: snow fraction, snow grain size, vegetation fraction, rock fraction, ice fraction, and shade fraction from the SCAG algorithm and snow darkening, radiative forcing, and snow grain size from the DRFS algorithm.

October 15, 2026
New version release: IceBridge BedMachine Greenland, Version 7
IceBridge BedMachine Greenland, Version 7 is now available at the NASA National Snow and Ice Data Center Distributed Active Archive Center (NSIDC DAAC). This data set contains a bed topography and bathymetry map of Greenland, as well as surface elevation and ice thickness data. This version of the dataset uses Ice Flow Perturbation Analysis to better reconstruct the bedrock topography beneath the ice sheet.

Data set retirement: ATLAS/ICESat-2 L3A Along Track Coastal and Nearshore Bathymetry, Version 1
ATLAS/ICESat-2 L3A Along Track Coastal and Nearshore Bathymetry, Version 1 will be retired from the NSIDC DAAC on 23 November 2026.
