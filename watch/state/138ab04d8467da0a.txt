Cloud Properties - ISCCP H-Series CDR
Configuration Item ID: 01B-29
The Cloud Properties - International Satellite Cloud Climatology Project (ISCCP) H-Series Climate Data Record (CDR) focuses on the distribution and variation of cloud radiative properties to improve understanding and modeling of the way clouds affect climate. This dataset provides an improved understanding of the radiation budget, as well as specific insight on the relationship between clouds and the radiation balance. These data can be used to support many other cloud studies, including efforts to understand the long-term global hydrologic cycle. The dataset period of record includes data from 1983 to 2017.
