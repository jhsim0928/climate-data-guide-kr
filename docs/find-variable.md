# 변수로 찾기

찾는 변수를 넣으면 **그 변수가 있는 자료가 모두** 나옵니다. 자료마다 다른 변수 이름(`tp`, `PRECTOT`, `prate` …)은 [표준 변수 목록](variables.md) 기준으로 묶여 있어요.
마음에 드는 자료를 **비교에 넣기**로 담으면 [자료 비교](compare.md)에서 기간·해상도·상태를 나란히 볼 수 있습니다.
