# 자료 비교

비교하고 싶은 자료를 최대 4개까지 고르면 기간, 해상도, 갱신 상태, 대표 DOI, 후속 자료를 한 표로 보여줍니다.
**변수 찾기**에 "강수"처럼 입력하면, 고른 자료마다 해당 변수의 이름·단위와 **순간값·평균·누적 여부**를 나란히 비교할 수 있습니다.
