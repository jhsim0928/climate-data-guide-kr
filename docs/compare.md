# 자료 비교

비교하고 싶은 자료를 최대 4개까지 고르면 기간, 해상도, 갱신 상태, 대표 DOI, 후속 자료를 한 표로 보여줍니다.
**변수 찾기**에 "강수", "2m 기온", `tp`처럼 넣으면 자료를 고르지 않아도 **그 변수가 있는 자료가 모두** 나오고, 자료마다 변수 이름·단위와 **순간값·평균·누적 여부**를 함께 볼 수 있습니다. 자료마다 다른 변수 이름(`tp`, `PRECTOT`, `prate` …)은 CF 표준 이름을 기준으로 같은 변수끼리 묶었습니다 ([표준 변수 목록](variables.md)).
