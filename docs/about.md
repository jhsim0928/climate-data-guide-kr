# 소개·인용

## 왜 만들었나요

모델을 돌리거나 장기 분석을 하다 보면, 쓰던 재분석자료가 갑자기 갱신 종료되거나 다운로드 서비스가 바뀌어 일정이 꼬이는 일이 생깁니다. 이런 공지는 기관마다 포럼, 뉴스, 메일링 리스트에 흩어져 있어 놓치기 쉽습니다.

이 사이트는 다음 세 가지를 한곳에 모읍니다.

1. **어디서, 어떻게 받는지** — 공식 제공처, 계정 필요 여부, 예시 코드
2. **논문에 무엇을 적어야 하는지** — 데이터셋 DOI, 기술 논문, 사사 작성 요령
3. **지금 쓸 수 있는 상태인지** — 갱신 종료, 서비스 이전, 품질 문제, 후속 자료 계획

## 정리 원칙

- 모든 정보는 **공식 출처**에서 확인하고, 공지마다 원문 링크를 붙입니다.
- 각 데이터셋 페이지에 **마지막 확인 날짜**를 표시합니다. 날짜가 오래됐다면 공식 페이지를 다시 확인하세요.
- 데이터셋 이름, 변수명, DOI, 코드는 번역하지 않고 원문 그대로 둡니다.
- 자료 자체는 보관하거나 재배포하지 않습니다.

## 이 사이트 인용하기

논문의 Data availability 또는 Acknowledgements에 아래처럼 적어주시면 사이트를 계속 유지하는 데 큰 힘이 됩니다.

```text
기후데이터 길잡이 (Korean Climate Data Guide), https://data4researchers.kr/ (접속일 YYYY-MM-DD)
```

Zenodo DOI가 발급되면 이 자리에 DOI 인용 형식을 추가합니다. GitHub 저장소의 **Cite this repository** 버튼으로 APA·BibTeX 형식을 바로 복사할 수도 있습니다.

## 함께 만들기

- **데이터셋 추가**: [데이터셋 제안](suggest.md) 페이지에서 필요한 자료를 알려주세요.
- **수정 제안**: 각 데이터셋 페이지 제목 오른쪽의 연필 아이콘을 누르면 해당 정보 파일의 편집 화면으로 이동합니다.
- **공지 제보**: GitHub 이슈의 "데이터 변경·공지 제보" 양식을 이용해 주세요.
- 기여해 주신 분은 저장소의 기여자 목록과 `CITATION.cff`에 이름을 올립니다.
