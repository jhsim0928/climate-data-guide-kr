# 소개·인용

## 왜 만들었나요

모델을 돌리거나 장기 분석을 하다 보면, 쓰던 재분석자료가 갑자기 갱신 종료되거나 다운로드 서비스가 바뀌어 일정이 꼬이는 일이 생깁니다. 이런 공지는 기관마다 포럼, 뉴스, 메일링 리스트에 흩어져 있어 놓치기 쉽습니다.

이 사이트는 다음 세 가지를 한곳에 모읍니다.

1. **어디서, 어떻게 받는지** — 공식 제공처, 계정 필요 여부, 예시 코드
2. **논문에 무엇을 적어야 하는지** — 데이터셋 DOI, 기술 논문, 사사 작성 요령
3. **지금 쓸 수 있는 상태인지** — 갱신 종료, 서비스 이전, 품질 문제, 후속 자료 계획

## 정리 원칙

- 모든 정보는 **공식 출처**에서 확인하고, 공지마다 원문 링크를 붙입니다.
- 공식 페이지에서 직접 확인한 내용만 싣고, 바뀐 소식을 확인하면 고칩니다.
- 데이터셋 이름, 변수명, DOI, 코드는 번역하지 않고 원문 그대로 둡니다.
- 자료 자체는 보관하거나 재배포하지 않습니다.

## 함께 만들기

- **데이터셋 추가**: [데이터셋 제안](suggest.md) 페이지에서 필요한 자료를 알려주세요.
- **수정 제안·공지 제보**: 모든 페이지 맨 아래(데이터셋 페이지는 제목 아래에도)의 **정보 오류 신고**를 눌러 알려주세요. 운영자에게 바로 전달됩니다.
- 원하시면 도움 주신 분의 이름을 이 페이지에 올려 감사를 표하겠습니다.
