# 기후데이터 길잡이 { .visually-hidden }

대기·해양·해빙·극지·원격탐사 연구자를 위해, 분석에 필요한 **원자료의 출처, 받는 방법, 제공 기간, 활용 가능한 변수, 논문용 레퍼런스, 그리고 제공 중단·변경 공지**를 한곳에 정리합니다.

이 사이트는 자료를 직접 보관하지 않습니다. 모든 항목은 공식 출처로 연결됩니다. 현재 <!-- DATASET_COUNT -->개 자료(<!-- DOMAIN_COUNTS -->)를 정리했습니다. 일부 자료는 두 분야에 함께 실려 있습니다.

    <!-- DISCLAIMER -->

## 이런 분께 추천합니다

- 재분석자료를 모델 입력자료로 쓰며 장기 운영하는 연구자
- 하려는 분석에 맞는 자료를 찾는 연구자
- 쓰던 자료의 갱신 중단·버전 교체 여부를 확인해야 하는 연구자
- 여러 자료를 비교하거나 교차 검증하려는 연구자
- 대기·해양·해빙 전공은 아니지만, 연구에 기후자료가 필요해 어떤 자료가 있고 어떻게 쓰는지부터 알아보려는 연구자

## 자료 제공 기관의 최근 공지

자료를 만들거나 배포하는 기관(ECMWF·NASA·NOAA 등)이 발표한 제공 중단·지연·버전 교체 소식입니다. 제목을 누르면 기관의 원문 공지로 연결됩니다.

## 이렇게 쓰세요

- **자료를 고를 때** — 위쪽 대기·해양·해빙 메뉴에서 자료를 살펴보고, [자료 비교](compare.md)에서 여러 자료를 한 표로 비교합니다.
- **변수를 찾을 때** — [변수로 찾기](find-variable.md)에 "강수", "2m 기온"처럼 넣으면 그 변수가 있는 자료가 모두 나옵니다.
- **변수를 쓸 때** — 각 변수 옆의 순간값·평균·누적 표시와 '시간 표기 규칙'을 확인합니다. 같은 3시간 자료라도 의미가 다를 수 있습니다.
- **자료를 받을 때** — 각 데이터셋 페이지의 '받는 방법'과 '예시 코드'를 따라 합니다.
- **논문을 쓸 때** — 데이터셋 페이지의 '논문에 넣을 레퍼런스'에서 인용문과 BibTeX를 복사합니다.
- **새 자료로 옮길 때** — [세대별 비교](transitions.md)에서 이전 자료와 무엇이 달라졌는지, 바꿔 쓸 때 주의할 점을 확인합니다.
- **변경 소식을 놓치기 싫을 때** — [중요 공지 알림 신청](subscribe.md)에서 데이터셋과 공지 구분을 골라 메일로 받습니다.
- **필요한 자료가 없을 때** — [데이터셋 제안](suggest.md)으로 알려 주세요.
