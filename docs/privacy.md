# 개인정보 처리방침

기후데이터 길잡이(이하 "사이트")는 중요 공지 알림 메일 발송, 데이터셋 제안·정보 오류 신고 접수에 필요한 최소한의 정보만 수집합니다.

## 1. 수집 항목과 목적

| 수집 항목 | 목적 |
|---|---|
| 이메일 주소 | 신청한 데이터셋의 변경 공지 메일 발송, 신청 확인 메일 발송 |
| 선택한 데이터셋, 공지 구분 | 원하는 공지만 골라 보내기 위함 |
| 신청 일시, 확인 일시 | 동의 이력 확인 |
| 신청한 페이지의 언어(한국어·영어) | 같은 언어로 메일 발송 |
| 소속 유형, 신분, 연구 분야 (선택) | 이용자 구성 통계 — 다룰 자료 선정과 사이트 개선. 개인별로 공개하거나 다른 목적에 쓰지 않음 |
| 데이터셋 제안 내용, 제안자 이름·소속·연락처(선택) | 제안 검토, 답변, 원하실 경우 기여자 표시 |
| 정보 오류 신고 내용, 신고한 페이지 주소, 답변 받을 이메일(선택) | 사이트 정보 수정, 답변 |
| 사이트 의견 내용, 답변 받을 이메일(선택) | 사이트 개선, 답변 |

회원가입이나 로그인은 없으며, 위 항목 외의 정보는 받지 않습니다.

## 2. 보유 기간

- 알림 신청 정보: 수신 거부(구독 해지)를 요청하면 **지체 없이 파기**합니다. 신청 후 확인 메일의 링크를 누르지 않은 정보는 30일 안에 삭제합니다.
- 데이터셋 제안·정보 오류 신고·의견: 검토와 답변을 위해 보관하며, 삭제를 요청하시면 지체 없이 파기합니다.
- 서비스를 종료하는 경우 모든 정보를 파기합니다.

## 3. 제3자 제공

수집한 정보를 다른 사람이나 기관에 제공하지 않습니다.

## 4. 처리 위탁

사이트 운영을 위해 다음 서비스를 이용합니다.

| 수탁자 | 위탁 업무 |
|---|---|
| Google LLC (Gmail, Google Sheets, Google Apps Script) | 알림 신청·데이터셋 제안·오류 신고·의견 보관, 확인 메일 및 알림 메일 발송 |
| GoatCounter | 쿠키 없는 방문 통계 집계 (개인 식별 정보 저장 없음) |

Google의 서버는 국외에 있으므로 신청 정보는 국외(미국 등)에 보관될 수 있습니다. 이전 시점은 신청서를 제출할 때이며, 전송 방법은 암호화된 인터넷 통신(HTTPS)입니다.

## 5. 수신 거부와 정보 삭제

모든 알림 메일 하단의 **수신 거부** 링크를 누르면 바로 처리되며, 신청 정보가 삭제됩니다. 아래 문의처로 요청하셔도 됩니다.

## 6. 방문 통계

방문자 수 집계에는 쿠키를 쓰지 않는 도구(GoatCounter)를 사용합니다. 어느 페이지가 몇 번 열렸는지, 대략적인 국가·브라우저 종류 같은 통계만 남고, 개인을 식별할 수 있는 정보는 저장하지 않습니다.
