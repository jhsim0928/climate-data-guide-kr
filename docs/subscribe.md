# 변경 알림 신청

데이터 제공 중단, 서비스 이전, 품질 문제 같은 공지가 새로 올라오면 메일로 알려드립니다. **원하는 데이터셋과 공지 구분만 골라서** 받을 수 있어요.

!!! tip "확인 메일이 스팸함으로 갈 수 있어요"
    신청 후 받은편지함에 확인 메일이 없으면 **스팸함**을 확인해 주세요. 스팸함에 있었다면 **스팸 아님**으로 표시해야 이후 알림도 받은편지함으로 들어옵니다. `data4researchers@gmail.com`을 연락처에 추가해 두시면 더 확실합니다.

## 알림은 이렇게 보내드려요

- 공지는 운영자가 공식 출처를 확인한 뒤에만 사이트에 올라가고, 그때 메일이 나갑니다. 확인되지 않은 소식은 보내지 않습니다.
- 새 공지는 하루 한 번(오전 9시 무렵) 모아서 한 통으로 보내드립니다.
- 처음 신청하면 확인 메일이 갑니다. 메일 안의 **신청 확인하기**를 눌러야 등록이 끝납니다. 메일이 보이지 않으면 **스팸함**을 확인하고 '스팸 아님'으로 표시해 주세요.
- 메일마다 수신 거부 링크가 들어 있고, 언제든 바로 해지할 수 있습니다.
- 공지 구분 기준은 [중요 공지](notices.md)의 **중요 · 주의 · 안내**와 같습니다.
