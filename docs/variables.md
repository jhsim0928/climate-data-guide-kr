# 표준 변수 목록

같은 물리량이라도 자료마다 변수 이름과 단위가 다릅니다. 예를 들어 총강수는 ERA5에서 `tp`, MERRA-2에서 `PRECTOT`, NCEP 재분석에서 `prate`입니다.
이 표는 사이트에 정리된 변수를 국제 표준인 **CF 표준 이름**(netCDF 기후자료 메타데이터 규약) 기준으로 묶은 것입니다. [자료 비교](compare.md)의 **변수 찾기**가 이 목록을 씁니다.

- 표준 변수 이름을 누르면 그 변수가 있는 자료를 모두 보여 주는 변수 찾기로 이동합니다.
- 표 오른쪽 위 **엑셀로 저장**으로 표를 내려받을 수 있습니다.
- 같은 표준 변수라도 **단위와 시간 특성(순간값·평균·누적)은 자료마다 다릅니다.** 각 자료 페이지의 '활용 가능한 변수'에서 확인하세요.
- CF 표준 이름 전체 목록: [CF Standard Name Table](https://cfconventions.org/Data/cf-standard-names/current/build/cf-standard-name-table.html)
