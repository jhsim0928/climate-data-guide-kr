# Standard variables

The same physical quantity has different variable names and units in different datasets — total precipitation is `tp` in ERA5, `PRECTOT` in MERRA-2 and `prate` in the NCEP reanalyses.
This table groups the variables listed on this site by **CF standard name** (the metadata convention for climate data in netCDF). **Find a variable** on [Compare datasets](compare.md) uses this list.

- Click a standard variable to list every dataset that has it.
- Use **Save as Excel** above each table to download it.
- Datasets grouped under the same standard variable can still differ in **units and time convention (instantaneous, mean, accumulated)** — check the variables section of each dataset page.
- Full list of CF standard names: [CF Standard Name Table](https://cfconventions.org/Data/cf-standard-names/current/build/cf-standard-name-table.html)
