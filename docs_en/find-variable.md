# Find by variable

Type a variable to list **every dataset that has it**. Different short names for the same quantity (`tp`, `PRECTOT`, `prate` …) are grouped as in [Standard variables](variables.md).
Use **Add to compare** on the datasets you like, then open [Compare datasets](compare.md) to see their period, resolution and status side by side.
